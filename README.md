Tienda de Ropa - Proyecto Final PHP

Este es un proyecto de una tienda de ropa desarrollado en PHP y MySQL. Incluye un panel de administración para gestionar usuarios y productos, un catálogo para vendedores, un carrito de compras y generación de facturas.

 Instrucciones para ejecutar el proyecto

1. *Descargar el código:* Descarga este repositorio como archivo ZIP o clónalo usando Git.
2. *Mover a XAMPP:* Coloca la carpeta del proyecto dentro de C:\xampp\htdocs\.
3. *Importar la Base de Datos:* Abre phpMyAdmin (http://localhost/phpmyadmin), crea una base de datos llamada almacen_ropa e importa el archivo .sql que se encuentra en este repositorio.
4. *Configurar la conexión:* Revisa el archivo config/db.php y asegúrate de que el usuario (por defecto root) y la contraseña coincidan con tu configuración local.
5. *Ejecutar:* Abre tu navegador y ve a http://localhost/tienda_ropa (o el nombre de tu carpeta).
